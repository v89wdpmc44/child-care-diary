# 让人头痛的“偏头痛”

> 更新时间：2026-09-16 (UTC+8)

“世上病有千万种，唯有偏头痛最难受”，相信很多人都有过偏头痛的困恼，被这烦人的病症折磨着。

泉州市中医院脑病科主治医师王锡滨表示，近年来，偏头痛逐渐呈现年轻化趋势，不少人年纪轻轻就患上偏头痛。

王锡滨介绍， 偏头痛是一种多发而常见的神经系统疾患，是头痛的一种，属于原发性头痛，是指反复发作的一侧或是两侧的搏动性头痛。需要注意的是，一次或是两次的发作不能诊断为偏头痛。

该病多起病于儿童和青春期，中青年期发病达高峰，女性多于男性，常有遗传背景，是一类有家族发病倾向的周期性发作疾病。疼痛时伴有恶心和呕吐，经过一段歇期后再次发病，在安静、黑暗环境内或睡眠后头痛缓解。

**偏头痛是如何发生的？**

**气候因素**

暴晒、吹风、寒冷刺激等都会引发偏头痛。当气温升高时，各种头痛发作的可能性明显增高。

**嗅觉因素**

即使好闻的气味，浓度过高也会诱发偏头痛，如油漆、香水、某些花或其它一些气味也会引发偏头痛。

**睡眠因素**

睡懒觉、熬夜等不规律的睡眠以及严重睡眠不足都会引发偏头痛。

**饮食因素**

如奶酪放置过久会引起蛋白质分解，释放出酪胺，食用后会诱发头痛。红酒和冷荤菜中同样也含有酪胺，不应过量食用。同时经常食用巧克力、酒精饮料、柠檬汁、生冷食物等刺激性食物或吸烟、喝酒等均会引发偏头痛。另外进食少或饥饿也可诱发。

**心理因素**

紧张、忧虑、焦虑、生气、激动等剧烈的情绪刺激会引发偏头痛。

**高强度运动及不良体态**

运动强度过高，体力消耗过大会造成颈部及头皮血管膨胀，从而引发头痛。

不良的体态，如耸肩、坐在没有靠背或靠背过低的椅子上、接电话时把听筒夹在肩膀上、办公桌电脑显示器的位置过高或过低等。

**药物因素**

过量服用硝酸甘油、利血平、雷尼替丁等药物会诱发偏头痛。

**环境因素**

研究表明，持续尖锐的噪音会导致人面部血管扩张以及刺激大脑神经从而引发偏头痛。强烈的光照会容易令人疲劳、烦躁、具有一定挑衅性和攻击性，从而刺激大脑引发偏头痛。

**内分泌因素**

约70%的偏头痛发生在女性经期前后，因此可以认为激素的波动可造成偏头痛。除此之外口服避孕药、绝经期、激素替代治疗时也可引发偏头痛。

**发生偏头痛 ****可以这样做**

**自我按摩**

可将双手的十个指尖放在头部最痛的地方，像梳头那样进行轻度的快速按摩，每次按摩一百个来回，每天早、中、晚饭前各做一次。

平日里可用指尖像洗头那样抓绕，或者用木齿梳子梳头等从鬓角朝额头向后脑勺缓慢圆周运动等进行头部按摩。

另外还可揉太阳穴，每天清晨醒来和晚上睡前，用双手中指按太阳穴转圈揉动，先顺揉，再反方向揉，这样反复几次，连续数日，偏头痛可减轻。

**良好的睡眠**

睡觉时尽量不要俯卧，因为这种睡觉姿势会使颈部肌肉发麻，加重头痛。

**热姜水泡手**

偏头痛发作时可将双手浸没于一壶热姜水中，水温以手入水后能忍受的极限为宜，坚持浸泡15分钟至30分钟左右，便可使手部血管扩张，脑部血液相应减少，从而使偏头痛逐渐减轻。

**及早治疗**

轻度偏头痛服用止痛药仍无法缓解，严重的恶心呕吐，以及中、重度的偏头痛；还有特殊类型的偏头痛，如偏头痛性脑梗死、偏头痛性癫痫，上述情形应及时就医。

**中药塞鼻**

取川芎、白芷各15克，再加冰片即可。在治疗头痛时，可用绸布包裹塞右鼻，一般塞15分钟左右便可止痛。

**巧用速效救心丸**

速效救心丸含有川芎、冰片，具有缓解血管痉挛、降低血管阻力，改善微循环，显著增加脑血流量，对血管性头痛和神经性头痛有显著的即时效果，在头痛发作时可口服8-12粒。

**注意科学饮食**

忌食巧克力、咖啡和可可等能够引起血管收缩的食物，还有延迟用餐甚至禁食也可诱发头痛，尽量避免。可多食用大豆、海产品、核桃等含镁元素丰富的食物。

**缓解偏头痛 ****可以这样吃**

**花生**

花生是一种比较容易买到的干果，味道美味，头疼发涨的时候可以嚼几颗花生，最好是晒干的。

**瓜子**

瓜子也是很不错缓解头疼的食物，选择吃生瓜子，不易上火。

**核桃**

核桃有补脑健脑的作用，它同样适用于缓解头疼，可以当零食吃，也可以放在汤里炖制，营养丰富。

**腰果**

腰果适当吃一些可以缓解头疼，但吃多了易上火。

**杏仁**

杏仁的营养价值很高，杏仁也能减轻头疼。其他的食物如瘦肉，杂粮，黄豆，猕猴桃等等都可以减轻头痛。
